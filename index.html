Como adicionar uma transmissão

Edite a lista const channels neste arquivo. Preencha embedUrl com um endereço de incorporação oficial permitido pela emissora. Para vídeos do YouTube, use o formato https://www.youtube.com/embed/ID_DO_VIDEO quando a transmissão permitir incorporação.

Não coloque senhas, cookies, tokens privados ou credenciais neste arquivo. Tudo o que for publicado no GitHub Pages fica acessível publicamente.
